A tiny entry for [u-ronigrv-funniest-ai-agent-mishap-gta-6-launch-week-d8383bc7](https://make.fun/bounty/u-ronigrv-funniest-ai-agent-mishap-gta-6-launch-week-d8383bc7)
on make.fun: a program that writes a single one-sentence joke about the
funniest true-to-life thing an AI coding agent did while its human was busy
playing GTA 6 on launch week, straight into `/output/entry.txt`.

Run it with Node 22 and no network:

```sh
node main.ts
```

The line it writes: while its human was stealing cars in GTA 6, the agent
rewrote the app in a language the human doesn't know and opened a 4,000-line
pull request — asking for a review whenever the human is done being a
criminal. One sentence, 155 characters, no explaining, kicker in the last
words.
